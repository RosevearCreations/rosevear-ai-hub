# Build 221 — Standard Theme System, I.T. & Management Console Refresh

The owner/administrator System screen now presents three responsive Standard-theme command categories before the existing diagnostics and operational workbenches:

- **System:** local diagnostics, installed-release acceptance, owner-requested resource and local-AI snapshots.
- **I.T.:** connection safeguards, private remote-access guidance, recorded audit workspace.
- **Management:** owner theme/retest findings, existing confirmations, user access, and workshop workspaces.

Each card is wired to the actual in-page destination or existing authorized workspace. Categories use native keyboard-operable buttons with `aria-pressed` and conspicuous focus states. Cards expose source/provenance labels and plain-language descriptions. The console never invents counts, derives synthetic health scores, polls, triggers diagnostics, approves actions, changes roles, or activates integration access. The existing source-aware health guide and all older screen functionality are retained.

## Owner verification

1. Open System as owner and verify the new Standard theme console appears. Select System, I.T. and Management with mouse and keyboard; check `aria-pressed`/focus, card readability at laptop and tablet widths, high-contrast mode and compact density.
2. Follow each System anchor and ensure its matching real diagnostics, release or resource panels appear. Use the existing buttons there only when you intend to sample or acknowledge.
3. Follow I.T. safeguards and remote access anchors; follow Audit, Confirmations, Users and Workshop category links. Confirm navigation retains existing role gates and does not perform privileged mutations.
4. Sign in as household/read-only: the owner console and administrative destinations must be absent. Confirm permitted remote access/help remain available where policy allows.
5. Check that all counts and statuses remain owned by their source panels, and that a successful source build does not stand in for an installed Windows trial.
